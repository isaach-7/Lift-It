# LiftIt fonts

Self-hosted Latin WOFF2 subsets from @fontsource/barlow 5.3.0 and
@fontsource/roboto-slab 5.3.0. No runtime Fontsource dependency is required.

- Barlow by Jeremy Tribby: https://github.com/jpt/barlow
- Roboto Slab by Christian Robertson: https://github.com/googlefonts/robotoslab

The accompanying license files are preserved verbatim as third-party notices.
